======================================================================
1. WHAT THE PROJECT IS
======================================================================
An agentic AI travel planner (portfolio project). First scenario: Indore <-> Goa.
Stack: Python 3.12, FastAPI, Pydantic v2, strict mypy, Ruff. Frontend: React 19,
TypeScript, Vite. Planned: LangGraph, PostgreSQL/SQLAlchemy/Alembic, OpenAI LLM.
Hard rules: no invented travel data; every value labelled LIVE / CACHED_LIVE / MOCK;
money as integer minor units; booking stays disabled (BOOKING_ENABLED=false);
no secrets in files or logs; stop for owner review after every milestone.
